# Monster Hunter Portable 3rd HD: Soul Lock & Monster Vitality

A fan-made mod for Monster Hunter Portable 3rd HD on PPSSPP that introduces Soulslike-inspired camera targeting and a customizable monster HP display.

## Features

- **Soul Lock:** Lock the camera onto a selected monster.
- **Soul Track:** Automatically track the selected monster to keep the camera oriented toward it.
- **Monster Vitality:** Display a monster's name, current HP, and maximum HP.
- **Boss Vitality:** Optionally display HP only for monsters with a maximum HP of at least 100.
- **Vitality Colors:** Customize the HP display using white, black, light gray, dark gray, red, yellow, or green.

## Compatibility

- **Game:** Monster Hunter Portable 3rd HD
- **Game ID:** NPJB-40001
- **Emulator:** PPSSPP

Compatibility may vary depending on the game version and emulator configuration.

## Controls

Use the **L button and the directional pad** to control Soul Lock.

| Input | Function |
|---|---|
| L + Up | Enable Soul Lock |
| L + Down | Disable Soul Lock |
| L + Left | Switch to the previous target |
| L + Right | Switch to the next target |

**Soul Track** automatically follows the selected monster.

## Installation

1. Download `NPJB40001.ini` from this repository or from the Releases section.
2. Place the file in the PPSSPP cheats folder.
3. Launch Monster Hunter Portable 3rd HD.
4. Open the game's Cheats menu in PPSSPP.
5. Enable the mod and the features you want to use.

Make sure the cheat file matches the game's ID: `NPJB-40001`.

# Monster Hunter Portable 3rd HD: Soul Lock y Monster Vitality

Un mod independiente para Monster Hunter Portable 3rd HD en PPSSPP que incorpora fijación de objetivos inspirada en los juegos Soulslike y una interfaz personalizable para visualizar los HP de los monstruos.

## Características

- **Soul Lock:** Fija la cámara en un monstruo seleccionado.
- **Soul Track:** Sigue automáticamente al monstruo seleccionado y mantiene la cámara orientada hacia él.
- **Monster Vitality:** Muestra el nombre del monstruo, sus HP actuales y sus HP máximos.
- **Boss Vitality:** Permite mostrar los HP únicamente de los monstruos cuyo HP máximo sea de al menos 100.
- **Vitality Colors:** Permite personalizar el color de los HP entre blanco, negro, gris claro, gris oscuro, rojo, amarillo y verde.
